# Product upload samples

`example-parts-list.txt` is an explicitly fictional, two-part specification for the
structured upload path. Upload as a specification, extract, review and confirm.
It has no 3D model and does not need one to exercise supplier research.

`nasa-h2o2-apu-turbine-rotor-blade-section-s81367.pdf` is a one-page extract from
physical PDF page 111 (printed 5-12), Figure 5-5 of NASA CR-121214, *Design of H2-O2
Space Shuttle APU, Volume 1: APU Design* (January 1974).

- [Official report record](https://ntrs.nasa.gov/citations/19740007624)
- [Original PDF](https://ntrs.nasa.gov/api/citations/19740007624/downloads/19740007624.pdf)
- NTRS marks the report “Work of the US Gov. Public Use Permitted.”
- Extract SHA-256: `e3b0d5621ea66a0fd3f014a026c572f507d08ba998584429ba755145bf0854c7`.

The archival drawing is an OCR/source-grounding test, not a complete manufacturing
specification. S-81367 is a drawing identifier, not an established OEM part number.
Do not infer missing revision, material, tolerances, certification or full 3D
geometry. This NASA blade section is unrelated to the synthetic engine demo's
nozzle, vane and duct identities. Create a new product for it.
